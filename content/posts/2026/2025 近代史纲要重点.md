# 第一章

## （1）为什么帝国主义列强没能实现瓜分中国的图谋？试举例。


::folding{title="答案"}
1.重要原因：帝国主义列强之间的矛盾和互相制约。

2.最根本的原因：中华民族进行的不屈不挠的反侵略斗争。

3.1900年前后兴起的义和团运动就是一个突出的例子。

4.在义和团反帝爱国运动期间，中国人民以其不畏强暴、敢与敌人血战到底的英雄气概，打击和教训了帝国主义侵略者，使他们不敢为所欲为地瓜分中国。
::


## （2）反侵略战争失败的根本原因和教训是什么？


::folding{title="答案"}
1.社会制度的腐败。

2.经济技术的落后。

3.前者是更根本的原因。正是社会制度的腐败，才使得经济技术落后的状况长期得不到改变。

4.教训：争取民族独立、国家富强必须从根本上铲除半殖民地半封建社会制度；落后必然挨打。
::


# 第二章

## （3）19世纪60-90年代洋务派举办的洋务事业有哪些？


::folding{title="答案"}
1.兴办军用工业，如江南制造总局。

2.兴办民用企业，如汉阳铁厂。

3.建立新式海陆军，如北洋水师。

4.创办新式学堂，如京师同文馆，派遣留学生。
::


## （4）简述洋务运动失败的原因。


::folding{title="答案"}
1.甲午战争一役，标志着以“自强”“求富”为目标的洋务运动的失败。

2.洋务运动具有封建性，其指导思想是“中学为体，西学为用”，这就决定了它必然失败的命运。

3.洋务运动对列强具有依赖性。

4.洋务企业的管理具有腐朽性。
::


# 第三章

## （5）简述南京临时政府的性质。


::folding{title="答案"}
1.南京临时政府是一个资产阶级共和国性质的革命政权。

2.资产阶级革命派在这个政权中占有领导和主体的地位。

3.其制定的各项政策措施，集中代表和反映了中国民族资产阶级的愿望和利益，在相当程度上也符合广大中国人民的利益。

4.其颁布的《中华民国临时约法》是中国历史上第一部具有资产阶级共和国宪法性质的法典。
::


## （6）如何理解辛亥革命的历史意义？


::folding{title="答案"}
1.推翻了清王朝的统治，沉重打击了中外反动势力。

2.结束了中国延续两千多年的封建君主专制制度，建立了中国历史上第一个资产阶级共和政府，使民主共和的观念开始深入人心。

3.推动了中国人民的思想解放。

4.推动了中国的社会变革。

5.辛亥革命推动了亚洲各国民族解放运动的高涨
::


# 第四章

## （7）五四以前新文化运动有哪些局限性？


::folding{title="答案"}
1.主要是资产阶级民主主义的新文化反对封建主义的旧文化。

2.不能为人们提供一种有效的思想武器去认识中国，去对中国社会进行改造。

3.新文化运动的倡导者把国民性置于优先地位。

4.他们使用的是资产阶级形式主义的方法，看问题很片面。
::


## （8）十月革命怎样推动中国先进分子从资产阶级民主主义转向社会主义？


::folding{title="答案"}
1.十月革命发生在其国情与中国相同（封建压迫严重）或近似（经济文化落后）的俄国。因而对中国先进分子具有特殊吸引力。

2.十月革命诞生的社会主义俄国号召反对帝国主义，并以新的平等的态度对待中国，有利推动了社会主义思想在中国的传播。

3.十月革命中俄国工人、农民和士兵群众的广泛发动并由此赢得胜利的事实，给予中国先进分子新的革命方法的启示。

4.在十月革命后、五四运动前后的中国思想界，就产生了一批赞成俄国十月社会主义革命、具有初步共产主义思想的先进分子。社会主义开始在中国形成一股有相当影响力的思想潮流。
::


## （9）为什么说五四运动标志着中国新民主主义革命的开端？


::folding{title="答案"}
1.有彻底反帝反封建的革命性，有各族各界人民群众广泛参与的群众性。

2.中国工人阶级开始作为独立的政治力量登上历史舞台。

3.促进了马克思主义在中国的传播，促进了马克思主义同中国工人运动的结合。

4.为中国共产党的成立做了思想上干部上的准备。
::


## （10）新三民主义为什么能够成为国共合作的政治基础？


::folding{title="答案"}
1.民族主义中突出了反对帝国主义的内容。

2.民权主义中强调民主权利应“为一般平民所共有”。

3.把民生主义概括为“平均地权”和“节制资本”两大原则（后来又提出“耕者有其田”的主张）。

4.新三民主义的政纲同中国共产党在民主革命阶段的纲领基本一致，因而有了国共合作的政治基础。
::


## （11）为什么说“没有中国共产党，就不会有1924-1927年的大革命”？


::folding{title="答案"}
1.中国共产党提出的反对帝国主义、反对军阀的政治口号。

2.大革命是以国共合作为基础的统一战线的组织形式下进行的。而中国共产党正是国共合作的倡导者和统一战线的组织者。

3.大革命是近代中国历史上空前广泛而深刻的群众运动。而中国共产党正是人民群众的主要发动者和组织者。

4.大革命的主要斗争形式是革命战争，共产党员在战斗中更是身先士卒，起着先锋作用和表率作用。
::


## （12）中国共产党成立后，中国革命呈现了哪些新面貌？


::folding{title="答案"}
1.制订了民主革命纲领：最高纲领是实现社会主义、共产主义；最低纲领是打倒军阀，推翻国际帝国主义的压迫。

2.发动工农运动：组织工人罢工，组织农民运动。

3.进行国共合作。

4.开展大革命。
::


# 第六章

## （13）怎样评价国民党政府正面战场的地位和作用？


::folding{title="答案"}
1.在战略防御阶段，以国民党军队为主体的正面战场担负了抗击日军战略进攻的主要任务。

2.组织了淞沪、忻口、徐州、武汉会战等一系列大战役，并在台儿庄战役中取得大捷。

3.这一时期，国民党政府对日作战比较努力，但实行片面抗战路线，导致中国在短时间内丧失大片土地。

4.在战略相持阶段，国民党政府逐步转为消极抗战，战斗力日益下降，豫湘桂大溃败成为大后方人心变动的重要转折点。
::


## （14）什么是抗日战争中的两条不同抗战路线？


::folding{title="答案"}
1.是国民党的片面抗战路线和共产党的全面抗战路线。

2.片面抗战路线：即不敢放手发动和武装群众，将希望单纯寄托在政府和正规军的抵抗上。

3.全面抗战路线：即中国共产党实行全面抗战路线，充分动员和组织武装群众抗战，使抗日战争成为真正的人民战争。

4.两条不同抗战路线的存在，是中国抗日战争时期，中国一切问题的关键。
::


## （15）中国人民抗日战争在世界反法西斯战争中拥有怎样的地位？


::folding{title="答案"}
1.中国人民抗日战争是中国反法西斯战争的重要组成部分，中国战场是世界反法西斯战争的东方主战场。

2.中国人民的抗日战争开展时间最早、持续时间最长。中国是在亚洲大陆上反对日本侵略者的主要国家。

3.中国坚持持久抗战，抗击和牵制着日本陆军主力，并为同盟国军队实施战略反攻创造了有利条件。

4.中国作为亚洲太平洋地区盟军对日作战的重要后方基地，还为盟国提供了大量战略物资和军事情报。
::


## （16）抗日战争胜利的原因是什么？


::folding{title="答案"}
1.以爱国主义为核心的民族精神是中国人民抗日战争胜利的决定因素。

2.中国共产党的中流砥柱作用是中国人民抗日战争胜利的关键。

3.全民族抗战是中国人民抗日战争胜利的重要法宝。

4.世界所有爱好和平和正义的国家和人民、国际组织以及各种反法西斯力量的同情和支持。
::


# 第七章

## （17）第三条道路的主要内容和实质是什么？


::folding{title="答案"}
1.抗日战争胜利后，某些民主党派的领导人曾经鼓吹“中间路线”，企图在国共对立的纲领之外寻找第三条道路。

2.在政治上，“必须实现英美式的民主政治”，但不准地主官僚资本家操纵；在经济上，“应当实行改良的资本主义”，但不容官僚买办资本横行，走和平改良的道路。

3.他们所提倡的是资产阶级共和国的方案，主张的实质上是旧民主主义的道路。

4.中国在战后面临的是两种命运、两个前途的尖锐斗争。客观形势决定了中国没有走中间路线的余地。
::


## （18）近代中国存在哪三种建国方案？


::folding{title="答案"}
1.第一种方案先由北洋军阀后由国民党统治集团代表，主张实行大地主大资产阶级专政，使中国社会继续走半殖民地半封建的道路。

2.第二种方案由某些中间派别或中间人士代表，主张建立资产阶级共和国，使中国社会走上独立发展资本主义的道路。

3.第三种方案由中国共产党代表，主张建立工人阶级领导的以工农联盟为基础的人民共和国，走经过新民主主义逐步到达社会主义和共产主义的道路。

4.这三种方案在中国人民的实践中反复地受到检验。第三种方案最终赢得中国最广大人民群众包括民族资产阶级及其政治代表在内的拥护。
::
